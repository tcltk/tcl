# Crible d'Ératosthène, Tcl et autres langages

* `crible.tcl` : trois représentations Tcl (liste ordinaire + `lset`,
  `list.int` + tranches, octets en cases + tranches), chronométrées en
  créer / cribler / compter.
* `autres/` : le même crible en C, JavaScript, Python (liste, bytearray,
  NumPy si présent), PHP, Ruby, Perl.
* `comparer.sh` : lance le tout ; `COMPARAISON.md` : résultats et principes.
